# Lab 1: DDL (Data Definition Language) & DML (Data Manipulation Language)

## 🎯 Objective
To understand how to define database structures and manipulate data within them using basic SQL commands.

## 📝 Concepts Covered
*   **Creating Databases & Tables** (`CREATE DATABASE`, `CREATE TABLE`)
*   **Altering Table Structures** (`ALTER TABLE ADD`, `ALTER TABLE RENAME COLUMN`)
*   **Dropping Tables** (`DROP TABLE`)
*   **Inserting Data** (`INSERT INTO`)
*   **Updating Data** (`UPDATE ... SET`)
*   **Deleting Data** (`DELETE FROM`)
*   **Basic Data Viewing** (`SELECT * FROM`)

## 🚀 Instructions
1. Run the `queries.sql` script in your SQL environment.
2. The script first sets up the `Student` and `Course` structures.
3. It modifies the structure of the `Student` table to accommodate more details.
4. Finally, it inserts 5 sample records and performs various updates and deletions to test the DML commands.
