## 📌 Overview

This project is divided into **7 structured labs**, starting from basic Database Design and Table Creation, all the way to complex nested Subqueries and Analytical JOINs. The queries are designed around a generic **College Database** model involving Students, Courses, Departments, Faculty, and Enrollments.

## 📂 Repository Structure

| Lab | Topic | Description |
| :--- | :--- | :--- |
| **[Lab 1](./Lab_1)** | `DDL` & `DML` | Creating databases, tables, altering columns, and performing basic CRUD operations. |
| **[Lab 2](./Lab_2)** | `Database Design` | Entity-Relationship (ER) Diagram modeling and creating relational tables with primary and foreign keys. |
| **[Lab 3](./Lab_3)** | `Data Insertion` | Inserting realistic data into the relational schema. |
| **[Lab 4](./Lab_4)** | `Data Retrieval` | Read-only SELECT queries utilizing aliases, WHERE clauses, sorting, and limits. |
| **[Lab 5](./Lab_5)** | `JOINs` | Utilizing INNER JOINs to combine data across multiple tables. |
| **[Lab 6](./Lab_6)** | `Aggregation` | Utilizing GROUP BY, HAVING, and aggregate functions (COUNT, MIN, MAX). |
| **[Lab 7](./Lab_7)** | `Subqueries` | Implementing single-row, multi-row (IN), and analytical nested subqueries. |

---

## 🚀 How to Use

1. Clone this repository.
2. Open your preferred SQL IDE (e.g., **Oracle SQL Developer**, **Live SQL**, or **MySQL Workbench**).
3. Navigate to **Lab 1** or **Lab 2** to initialize the database schema.
4. Execute the `insert_data.sql` script in **Lab 3** to populate the tables with sample data.
5. Proceed to run the queries from Labs 4 through 7 to practice data retrieval and analysis!
