# Lab 4: Data Retrieval Using SQL (Read-Only Queries)

## 🎯 Objective
To practice retrieving, filtering, and sorting data from existing database tables without modifying the underlying records.

## 📝 Concepts Covered
*   **Basic Retrieval**: Fetching specific columns vs. all columns.
*   **Column Aliasing (`AS`)**: Temporarily renaming output columns for better readability.
*   **Conditional Filtering (`WHERE`)**: Narrowing down results based on specific conditions (e.g., strings, numbers, dates).
*   **Sorting Data (`ORDER BY`)**: Arranging results in `ASC` (ascending) or `DESC` (descending) order.
*   **Limiting Results (`LIMIT` / `FETCH FIRST`)**: Constraining the number of output rows.
*   **Derived Output**: Calculating computed fields on the fly (e.g., calculating Age from Date of Birth).

## 🚀 Instructions
Run the `queries.sql` script. Ensure that the database has been populated with the data from **Lab 3** before executing, or the queries will return empty sets!
